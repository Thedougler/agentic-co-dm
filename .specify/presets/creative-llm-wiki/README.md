# `creative-llm-wiki`

Repository-owned, inactive Spec Kit meta-preset for the hybrid SDD route. The package contains one selectively adapted contract template and review metadata; it is validated in place and is not added to `.specify/presets/.registry`.

The provenance file keeps candidate community packages pinned and untrusted. Their patterns are references only. No candidate is installed as a runtime dependency, and existing Spec Kit, wiki, canon, Work, reveal/visibility, and maintenance authorities remain in force.
