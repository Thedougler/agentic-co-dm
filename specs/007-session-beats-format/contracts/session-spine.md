# Contract: Session spine

The interface is the session-level chart in the session folder. Co-DM is the writer.

## Identity

1. `type: session-prep`. Filename `Session-<N>-00-<Spine-Title>.md`.
2. One spine per session folder.
3. Evidence: `_raw/Session-11-00-Birds-of-a-Feather.md`.

## Jobs

4. The DM can name length, prize, opposition, dramatic spine, and the numbered beat list with links.
5. Each listed beat has purpose, table sees, truth, pressure, if they break, and landing.
6. The spine does not duplicate Scene ends when, Zones, or Be ready for. Those live on beat cards.
7. Run tonight starts from the linked Hook card, not from a cockpit on the spine.

## Ingest

8. Filing preserves the Session 11 session-note shape (skeleton, summaries, links).

## Out of contract

Beat cockpit. Companion encounter tables’ internal layout. Planning-only `session-skeleton.md` candidate pools (not the filed page).
