# Contract: Work

Co-DM output is Work addressed to the DM. Players see nothing until the DM accepts and presents.

## Propose

Input: DM request in prep or wrapup, plus wiki pages.

Output: inspectable text addressed to the DM. **Do not create a wiki page yet** (FR-019).

Done when:

- Addressed to the DM.
- Citations for canon claims; invention flagged and grounded (wiki pages and/or D&D 5e rules).
- Does not contradict existing pages (or names the conflict).
- The DM can accept, edit, or reject before any wiki write.
- Inspectable after the fact (FR-013).

## Decide

DM accepts (optionally after edit), or rejects.

- Accept → then file a wiki page (`lifecycle: accepted`, or `proposed` if the DM asked to park it). Eligible for table and for canon if the DM says so.
- Reject → no wiki page. Not presentable. Not canon.

## Canon

Only accepted Work may change wiki facts. Wrapup proposes session outcomes first, then updates owner pages after accept.

## Windows

- Prep: author Work. Stage Foundry from accepted Work.
- Session: no Co-DM.
- Wrapup: file outcomes; still no live table agent.
