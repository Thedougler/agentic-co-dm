# Contract: D&D content guidance and combat instance

The interface is a job. Co-DM is the writer. The DM is the human reader of Work.

Authorities stack with 010. This contract does not cancel writing-for-agents, copy-writer, theatre of the mind, or vault format.

Naming a research pass on an ordinary wiki write is a fail. Requiring a named person's process as the only method is a fail. Number-only combat math with no named beat is a fail.

## Guidance jobs

| # | Job | Result |
|---|---|---|
| 1 | Create or change a D&D content skill | Research, then integrate outcomes into that skill. writing-for-agents. |
| 2 | Create or change a standing instruction that creates D&D wiki content | Same as 1 |
| 3 | Ordinary wiki NPC page, guidance already exists | Follow guidance. No fresh expert-research pass |
| 4 | Guidance that copies an expert's process as the only valid method | Incomplete |
| 5 | Guidance invented in a vacuum when designers already solved it | Incomplete |
| 6 | Official sources silent; high-quality homebrew used | Allowed |
| 7 | Proprietary book text pasted into guidance or Work | Fail |

## Combat-instance jobs (first instance)

| # | Job | Result |
|---|---|---|
| 8 | Custom ability / phase / legendary action | Communicates lore, origin, or stakes a second person can state |
| 9 | Custom feature that only adds damage or HP | Incomplete |
| 10 | Encounter with a named place | At least one mechanical pressure belonging to that place |
| 11 | Named place described only, never acts | Incomplete |
| 12 | Substantial homebrew rewrite | Names the plot or character beat it manifests |
| 13 | Homebrew whose only reason is "harder" | Incomplete |
| 14 | Stock published opposition used unchanged | Pass without custom features |
| 15 | DM explicitly asks for a stock/featureless fight | Override. Combat instance not required |
| 16 | Light reskin, how the creature acts is unchanged | No tectonic plot-shift required |

## Passage rules

1. Research fires on guidance jobs, not on ordinary wiki writes.
2. Integrate outcomes into one source. Do not add a competing procedure.
3. Expert techniques are sources and examples, not the only valid method.
4. Named published designers and documented craft first; high-quality homebrew only if those are silent.
5. Never paste proprietary book text.
6. Combat custom features serve a named narrative beat.
7. A named encounter place has mechanical pressure.
8. Substantial homebrew manifests a named plot or character beat.
9. Craft owners of facts, math, and procedure stay owners.
10. Spoken look stays theatre of the mind.

## Out of contract

Legacy wiki pages. Foundry play-surface staging. Research on every wiki write. A seventh skill. A second `AGENTS.md` table. Requiring legendary actions on every creature.
