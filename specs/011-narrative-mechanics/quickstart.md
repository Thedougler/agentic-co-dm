# Quickstart: Expert-Grounded D&D Content Guidance

Prove the feature by classifying jobs. Do not rewrite `legacy/` to “fix” them. Do not require a live web call.

## Prerequisites

- Branch `011-narrative-mechanics`
- Spec [spec.md](./spec.md), contract [contracts/dnd-content-guidance.md](./contracts/dnd-content-guidance.md)
- `writing-for-agents` description and body include the D&D content guidance branch (research → integrate outcomes)
- `homebrew-monsters-5e` and `encounter-prep` carry the combat-instance outcomes (or already matched)

## 1. Guidance vs content (P1, SC-001, SC-002)

Cover contract jobs 1–7.

- New or edited D&D content skill: research then integrate outcomes. Fail if vacuum-invented. Fail if an expert's process is the only allowed method. Fail if proprietary book text is pasted.
- Ordinary wiki page: no fresh research pass. Fail if the job is scored incomplete for skipping one.

## 2. Combat features and homebrew (P2–P3, P5, SC-004, SC-006)

- Custom feature: a second person can state lore, origin, or stakes. Fail if it only changes numbers.
- Substantial homebrew: names the plot or character beat. Fail if the only reason is difficulty.
- Stock opposition used unchanged: pass without custom features.
- Light reskin: no tectonic plot-shift required.

## 3. Named place (P4, SC-005)

Encounter with a named place: at least one mechanical pressure that belongs to that place and would change strategy. Fail if the place is flavor-only. Fail if a featureless skirmish the DM asked for is required to grow a lair.

## 4. Override and exemptions (SC-007)

DM asks for a stock/featureless fight: combat instance not required. Stock published opposition used unchanged: not failed for lacking custom features.

## 5. Pointers, not copies (Constitution IX)

- `writing-for-agents` is the research loop. No seventh skill. No second table in `AGENTS.md`.
- Combat outcomes live on `homebrew-monsters-5e` and `encounter-prep`. They do not steal math ownership.
- `docs/agents/work.md` does not require expert web research on every vault write.

## 6. Legacy untouched (SC-008)

This change set does not rewrite `legacy/` or restyle historical wiki pages solely to match the default.

Pass: steps 1–6 hold. Fail any step → the default is not in force yet.
