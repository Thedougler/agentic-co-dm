# Locations

## At a Glance

**Core truth.** This page is the sitting index for named waters, islands, and inland sites in the [[shattered-sea]]. Each link points to the owner page for that location.

**Why it matters.** The index lets the DM move from a broad regional name to the page that holds its current facts, pressures, and table use.

**Scope.** It covers the [[crown-islands]], [[central-strait]], [[Midchain]], [[aruhe]], and [[verdant-teeth]] areas listed below.

## Current Truth

The index groups the named locations by broad area. The listed owner pages remain the source for each location's specific truth. [[vault-of-the-first-factor]] is recorded here as an unconfirmed Midchain limestone-spire rumour.

The Crown-water group is [[crown-islands]], [[Harwick]], [[calven-and-calveno]], [[Aldenmere]], [[Stenmark]], [[high-eyrie]], [[calders-tooth-and-port-tidefall]], [[Greyteeth]], [[Blackrule]], and [[sarns-landing]].

## Limits

This page does not replace an owner page, establish travel times, or resolve contradictions between location pages. It records only the grouping and links present in the source index.
## At the Table

**Players notice.** The party encounters a place name in play, on a chart, or in a conversation and can use this index to locate the corresponding owner page.

**This explains.** The index distinguishes broad regions from the named sites filed beneath them.

**This enables.** The DM can open the relevant owner page without treating this index as the location's complete description.

**This warns of.** A name listed here is not evidence that its owner page is confirmed or safe; the [[vault-of-the-first-factor]] entry is explicitly unconfirmed.

## If This Is Changing

**Current pressure.** No single pressure changes this index; location-specific pressure belongs on the linked owner pages.

**Actors.** The linked location pages and their named inhabitants or factions own those pressures.

**Their aims.** No shared aim is established for the index.

**Without interference.** The index remains a navigation aid while the linked locations change independently.

**Visible sign.** A new named location or a changed owner page would require this index to be updated.

## Consequences

**Because this is true,** the DM can treat the linked owner pages as the location-specific source of truth.

**If exposed,** the unconfirmed status of [[vault-of-the-first-factor]] remains an open lead rather than a confirmed site.

**If disproved,** the relevant owner link or rumour entry must be corrected without changing unrelated locations.

**If changed,** [[shattered-sea]]'s navigation structure would need a corresponding index update.

**If exploited,** the index can reveal where the campaign has a named location page and where it does not.
