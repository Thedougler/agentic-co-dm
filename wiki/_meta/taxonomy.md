# Tag taxonomy

Max 5 domain/type tags per page. Lowercase or hyphenated. `visibility/` tags do not count toward the limit.

## Domain

| Tag | Use |
|---|---|
| `shattered-sea` | This campaign |
| `calveno` | Calven / Calveno city matter |
| `aruhe` | Hungry Isle matter |

| Tag | Use |

| `place` | Location or ship-as-place |
| `region` | Region-scale location |
| `item` | Named object |
| `creature` | Monster or other creature |
| `faction` | Organization, polity, or movement |
| `vehicle` | Named vehicle |
| `spell` | Named spell |

| `quest` | Campaign situation or objective |
