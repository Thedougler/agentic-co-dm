# Eliciting the voice

Ask in the DM's own terms. The aim is material specific enough to become a move — a vague preference
produces vague calibration, and calibration is what every drafting agent reads.

## Opening

Ask which they want to work from, and take both if offered:

- Written media they love — books, authors, a film whose staging they admire.
- Their own writing — anything they wrote unprompted, however old or rough.

Neither on hand → ask what they last read that made them want to write, and start there.

## Media follow-ups

Per named work, in this order. Stop as soon as the answers are concrete enough to name a move:

1. What does it do that you wish more books did?
2. Is there a scene or passage you still remember? What was happening in it?
3. What would you *not* want borrowed from it?
4. Where an author is named rather than a title — which of their books, and do they read the same to
   you or is one the outlier?

An answer like "the prose is great" is not yet usable → ask what the prose *does*: how long the
sentences run, how close it sits to the character, what it withholds.

Record the DM's own phrasing verbatim for the source note. Their words outrank any critic's, and a
paraphrase loses the thing that made it worth capturing.

## Sample follow-ups

Per sample:

1. When did you write this, and would you write it the same way now?
2. Anything in here you already know is bad?
3. Anything you would defend if an editor flagged it?

Question 3 is the one that matters most: it separates **signature** from **tic** before any
extraction starts, and the DM is the only source for that distinction.

## Recording the range

Ask whether the sample and the named works represent the whole voice or one mode of it. A profile
built from partial evidence and recorded as complete freezes a single register as law. Note the
answer in the source note beside the entries it produced.

## What never gets asked

Anything the files already answer. Read `vault/refs/stories/prose-aesthetic.md` and
`vault/refs/stories/banned-patterns.md` first — a question the profile already answers spends the
DM's attention on work already done, and re-asking a recorded preference reads as having lost it.
