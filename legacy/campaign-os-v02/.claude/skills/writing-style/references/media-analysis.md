# Turning a loved work into moves

A work the DM loves is evidence about the DM, not a source to draw from. This file converts it into
technique that can reach unrelated prose.

## Research before writing

Search externally for each work before recording anything about it — what critics and the author
identify about its construction. A move written from recall is unverified and often describes the
book's reputation rather than its craft.

Search for the mechanism, not the plot: how a named author builds dread, handles narrative distance,
paces a reveal, structures an ensemble, opens a chapter. Cite the URL in the influence entry.

Research comes back empty on a point → record that it did. An unsourced move is worse than a missing
one, because everything downstream treats the profile as settled.

## The transfer test

Every candidate move faces one question:

> Could this be applied to material with zero relationship to its source?

**Pass** — it is a technique. Record it.

**Fail** — it is borrowed content wearing a technique's clothes. Cut it.

Worked distinction, same source work:

- *"Ordinary domestic detail accumulates for several pages before the first sign that anything is
  wrong, so the reader's guard is down when it arrives"* — passes. Applies to any scene, any genre.
- *"A small town harbouring an ancient evil beneath its respectable surface"* — fails. That is the
  book's premise. Applying it produces that book again.

The tell is proper nouns. A move that needs a character, a place, or a plot beat to be stated is
content; state the mechanism underneath it instead, or drop it.

## Writing the entry

Per work, in `vault/refs/stories/influences.md`:

- **Moves that transferred** — each named, then stated mechanically, so it reads as an instruction
  rather than a description of the source.
- **Not an influence** — the parts of the work that must not reach this repo's prose: period diction,
  genre furniture, a structural habit that would break the register, a mannerism the DM named in the
  interview as unwanted.
- **Sources** — the URLs the research came from.

Name each move as a compact phrase the drafting skills can carry — *mundane-detail ramp*,
*ensemble convergence*, *withheld antecedent*. A named move gets reached for; a paragraph describing
one does not.

## Quotation

State every technique in your own words. Where one genuinely cannot be stated without the source's
phrasing: one quote per work, under fifteen words, attributed. Never reproduce passages, verse, or
lyrics from a source work in any file this skill writes.

## Films and adaptations

A film contributes staging and structure — how scale is framed, how a timeline compresses, how
parallel threads converge, what an adaptation cut and what that reveals about pacing. Record those
as moves like any other.

Where the DM prefers an adaptation to its source, keep the two as separate entries with separate
*not an influence* halves. Merging them produces exactly the prose the DM went to the adaptation to
get away from.
