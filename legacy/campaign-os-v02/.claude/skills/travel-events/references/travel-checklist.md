# Checklist (run before calling a leg's events done)

- [ ] Travel method and distance stated, not inferred; distance kept vague
      in play unless a route page's `travel_time:` or a live deadline
      fixes it.
- [ ] Standard queries run and pasted; existing route page read as the
      leg's baseline, or the gap flagged to the route drafting guide.
- [ ] Event count matches § Distance → event count.
- [ ] Every event states its party derivation (named PC thread, faction
      front, or spotlight need × a leg fact) — no event exists "because
      travel needs events," none selected by roll.
- [ ] Every event names what it advances (thread, relationship, resource,
      world knowledge) — Hard Rule 8.
- [ ] No two adjacent events share a type; ≥1 non-combat event (2+ event
      legs); ≥1 event states a real PC connection (Hard Rule 1).
- [ ] All five journey slots filled: departure cost, ≥1 named landmark
      (wonder-table row cited if used — picked, not rolled), events, toll
      (menu-sourced numbers), arrival-changed line.
- [ ] Travel roles offered to real PCs by name on every 2+ event leg; spotlight
      PC picked first.
- [ ] Every in-fiction roll (role check, hazard check) cites its DC tier
      and a real `roll-dice` result — never an invented number.
- [ ] Combat/drama-suite events handed to `encounter-prep`, not
      re-derived here.
- [ ] Recurring-candidate named entities handed to their drafting guide, not
      written inline.
- [ ] Every finding landed per the four-destination test
      (`route-escalation.md`); this skill wrote nothing but
      the events handed to `draft-moment`.
