# Out of scope

The shared routing table — canon content, the status/publish gates,
read-aloud prose craft, art, audio, faction clocks — binds via
`vault/refs/vault/_common/out-of-scope.md`. This skill's own neighbours, on
top of those:

- Ship stats/crew/upkeep/bastion/facilities/acquisition/variants/magical
  enhancements (`.claude/skills/draft-content/references/ship.md`); the session-wide prep
  protocol (`draft-run-guide`).
- A route page's standing facts — duration, traffic, hazards of the way
  itself (`.claude/skills/draft-content/references/route.md`); an encounter table's rows
  (`.claude/skills/draft-content/references/table.md`).
- A combat event's calibration (`encounter-prep`, Hard Rule 4); a named
  recurring entity's own page (`.claude/skills/draft-content/references/npc.md`, Hard
  Rule 4).
- Dice rolls (`roll-dice`, Hard Rule 2).
