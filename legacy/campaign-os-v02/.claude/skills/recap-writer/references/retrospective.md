# Retrospective (DM-only, optional)

The player-facing half of "after the session" is `vault/_templates/_episodes/_session_recap.md` +
`_templates/session-highlights.md`. This is the other half — the DM's own private
read on how the session ran, never shown to players, no wiki template
governance (`vault/episodes/` isn't a W1/W5-scoped root — `vault/_templates/_episodes/_session_ingest_review.md`
already lives there as a minimal resume-pointer, not a fully
template-governed page).

**Trigger:** the user asks for it explicitly ("session retro",
"retrospective", "how did that go") — never generated unprompted as part
of an ordinary RECAP pass. Skipping it is the normal case, not an omission
to flag.

**These questions are DM judgment, not something to derive from the
canon pages or transcript — ask, don't invent:**

```markdown
# Session NN — Retrospective

## What went well?

## What could be better?

## One thing to try next session
```

Ask the three questions together, record the DM's own words (lightly
cleaned, never rewritten to sound better), and stop — this file is a
private note, not prose to polish. `created`/`updated` are today's real
date, no `publish:` key at all (it's not a wiki page and never becomes one).
