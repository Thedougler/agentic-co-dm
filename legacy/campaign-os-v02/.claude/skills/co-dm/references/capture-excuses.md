# Capture discipline — why Hard Rule 2 has no exceptions

Read when a live moment tempts skipping the `## IMPROV` write — the
rationale behind Hard Rule 2, close every workaround by name:

| Excuse | Reality |
|---|---|
| "The transcript will catch it" | Audio may not be running, may miss a quiet aside, or this table might not record at all — `vault/episodes/<NNN>/table-notes.md` is the only durable record this skill controls, and it's the only one guaranteed to exist. |
| "It's too minor to write down" | INGEST decides what's canon-worthy later, not this skill mid-scene — today's throwaway vendor is tomorrow's recurring contact (`vault/campaigns/shattered-sea/npcs/` is full of pages that started this way). |
| "I'll remember it for the rest of the scene" | Nothing this skill does persists between turns except what's written to a file — a fact held only "in mind" is gone the moment context turns over. |
| "We'll sort it out after the session" | "After" is INGEST, and INGEST reads `vault/episodes/<NNN>/table-notes.md` as its second evidence source (transcript-ingest.md § Table-notes as a second evidence source) — an unwritten fact has nothing for INGEST to read. |

**Red flags — stop and write the block instead:**
- "I'll just keep this in mind"
- "it's on the recording"
- "not worth writing down"
- "I'll circle back to it"

All of these mean: write the `## IMPROV` block now, then answer the
table. The write costs one tool call; losing the fact costs a
contradiction later that `canon-review` has to untangle.
