# Stub-check miss — when it's fine to proceed

A stub-check miss is informative, not a blocker — it's the normal case for
something the table just invented. Don't stop to run a full `llm-wiki-query`
search under table pressure; a plain grep miss is enough to proceed to
improvising (Hard Rule 1) unless the name is close enough to an existing
entity that it might *be* that entity under a different spelling — then
ask, don't guess (Degrade by asking).
