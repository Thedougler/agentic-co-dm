# Session narration

A Beat file or a Last Time recap. Session-local. Still a picture first.

## Beat or run-guide step open

Same sensory bar as a depiction. The parent is `type: beat` or a
run-guide's numbered play H2. 90–150 words. Hook in the first two
sentences. A run-guide step continue (`mode: continue`) is 60–110 words:
only what changed, still hooked in line one. Long comma-linked clauses
carry the time; a run of short factual sentences finishes too soon.

A **call to action** is allowed when the table needs a push — "What do you
do?", "How do you stay ahead of it?". General. Not a binary or-menu. Not
the check's own solution. Own sentence after the picture, not folded in.
Hint-register toy is the default; CTA is earned.

Before any prompt, the picture makes the live affordances legible in the
fiction itself — the gap the surf leaves open, the tool in reach, the
ground that would hold — so the table sees what can be done without being
told what to do. An affordance is scenery with a use, never an option
list.

Skip the prompt when the picture already hands the table the live element.

`you` stays off the picture. The prompt is the one place the table is
addressed.

**Check is in the picture.** Parent has a `[!check]` or save → that
check's object is the toy. The last beats leave it live. The DM
speaks the picture, then calls the roll. No invented sentence
between them. The picture never names the skill or the DC.

## Recap (`mode: recap`)

Past tense. The party may be the subject. Last sentence is the hook the
first sample of tonight picks up. A pacing prompt is allowed as that hook.

## Done

Beat: italic picture, optional one-line prompt, no hidden DC, no
prescribed feeling. Recap: past tense, ends on tonight's hook.
