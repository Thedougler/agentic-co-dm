# Goal

`goal:` is the story or world fact this file tells the party — the lore
they need to progress. Fewest words that still name that fact. Texture,
gesture, and smell are not the goal.

Write it before the body. After Draft B, grade:

1. **Delivered.** A listener who heard only the body can restate the
   `goal:` without the frontmatter. If they cannot, the body failed.
2. **Quality.** [checklist.md](checklist.md),
   `vault/refs/stories/register.md`, and `npm run lint -- <path>` on
   the file (CampaignAward rides that pass). Evocative, vivid, detailed,
   focused. The last beat leaves something the table can act on.

A depiction's goal is still a world fact (what this thing *is* in the
setting), not a session beat.

Dialogue: the fact inside the line — the ask, the name, the price.
