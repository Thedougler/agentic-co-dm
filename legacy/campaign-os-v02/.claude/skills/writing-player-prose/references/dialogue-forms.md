# Dialogue forms

Line craft: `vault/refs/stories/prose-and-character-craft.md` § Dialogue
and § NPC entrance. The first line is a question or a demand. The table
has something to answer. A file that only informs, and never asks or
presses, is unfinished.

Single line: ≤ 20 words. Exchange: ≤ 75 words across the file (≤ 30s).
One speaker line past 20 words splits across beats or takes a cut-in.

## Single line

```markdown
*Nona Black-Jaw*: You sat at my table once. That buys you the truth said slow.
```

Speaker in italics. No quotation marks. No "she says".

## Exchange

```markdown
**Corven Ashe**: You cannot enter the house of Tyr!

**The Shape**: Tyr is not here. This is an empty box.
```

Bold speaker cues — a script, scannable across turns. Consecutive lines
by one speaker collapse into one.

## Done

A performer reads only words a character says. Anything else is in the
wrong file.
