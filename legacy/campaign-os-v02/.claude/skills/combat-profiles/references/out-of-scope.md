# Out of scope

- `vault/campaigns/shattered-sea/pcs/<name>.md` itself — `dnd5e-character-interview`'s exclusive territory;
  this skill only reads it.
- Designing the actual encounter around the calibration —
  `encounter-prep`'s job; this skill hands off the Effective CR Band,
  never builds the encounter.
- A homebrew creature's own design math — `.claude/skills/draft-content/references/monster.md`'s job; this
  skill's output is one input to that skill's difficulty check.
- Narrative PC primers (spotlight/pressure/avoid guidance) — a different
  qualitative document class; this skill is the quantitative "how much,"
  never the "what to do."
