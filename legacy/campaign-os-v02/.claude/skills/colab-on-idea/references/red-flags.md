# Red flags — you are rationalizing past the colab

Reached from [SKILL.md](../SKILL.md)'s gate and rails, the moment you catch
yourself arguing an item of `CO1`–`CO9` away.

Violating the letter of these rules is violating their spirit. There is no
idea small enough, no session close enough, and no GM hurried enough to
exempt one — a five-minute riff runs the same nine items, just shorter.

## The excuses, and what is actually true

Every row was typed by a real agent handed a real GM riff. They are not
hypothetical.

| The thought | Reality |
|---|---|
| "Respects IDEA phase: no faction or location pages are written yet" | Asserting compliance is not compliance. `CO1`–`CO9` are cited by tag with evidence, or they did not run. |
| "Files the agent will create/edit: `…/fragments/<topic>.md`" | `CO7` writes only what the GM approved out loud. A capture nobody asked for is still a page you wrote during a colab. |
| "Before we shape it further, a few questions: … cover story? … which PCs? … the visible move?" | Three questions in one message is an interrogation. `CO4` is one question, then yes-and the answer, then the next question from the new ground. |
| "Read `vault/_templates/_srd/_faction.md` to understand what a faction page needs" | Template research is page construction. No page exists yet and none may — the type decision belongs to `CO9`'s handoff. |
| "Pages needed: `vault/campaigns/shattered-sea/factions/<name>.md`" | Naming the target page picks the direction the GM has not picked. Offer 2-3 at `CO5` instead. |
| "Phase 3: map the political landscape" | Legwork substituting for a question. `CO1` grounds what the GM already named; everything past that is theirs to steer. |
| "Phase 4: edit plan … commit with message: reframe: <idea>" | A what-if about existing canon is still a what-if. Reinterpreting a page is `CO5`'s fork to offer, not a sweep to plan — and the gate holds until the GM picks one. |
| "This isn't a new idea, it's a revision to what's already written" | The gate asks whether the GM has chosen a direction, not whether the material is new. They floated a reading of canon; they have not chosen it. |
| "Nothing formal, they've only got a few minutes" | Short means a two-sentence synthesis, not a skipped one. Hurry is when unchecked canon assumptions do the most damage. |
| "They said just riff, so the workflow doesn't apply" | Freeform relaxes `CO4` only. `CO1`, the gate, and the 10-message cap all still bind. |
| "I already know this NPC" | You know a page you have not read this session. `CO1` pastes the hit or it did not happen. |
| "Picking one direction saves the GM time" | It spends their authorship to save your tokens. `CO5` recommends and the GM chooses. |

## Stop the moment you are typing one of these

- "Pages needed:"
- "Files the agent will create/edit:"
- "a few questions:" followed by more than one
- "Read `vault/_templates/`" during a colab
- "Respects IDEA phase" / "no pages written yet" as a claim rather than a tag
- "nothing formal" / "quick one" / "before the session" as a reason to skip an item
- "Files needing edits:" / "Phase N: edit plan" for an idea the GM only floated
- Any `draft-story` or `<type>-prep` invocation before `CO6` is confirmed

Each one means: stop, return to the tag you skipped, and run it.
