# Out of scope

The shared routing table — canon content, the status/publish gates, the
session run guide, read-aloud prose craft, art, audio, faction clocks —
binds via `vault/refs/vault/_common/out-of-scope.md`. This skill's own
neighbours, on top of those:

- A named/recurring antagonist's own page, Toy Chest, Three Villain
  Questions, or villain stat approach — `.claude/skills/draft-content/references/npc.md` exclusively.
- A reusable creature kind's own page, and the CR-math/stat-block design
  method itself — `.claude/skills/draft-content/references/monster.md` exclusively (§ Cross-skill coordination).
  This skill only applies that method inline, for a one-off creature with
  no page.
- Locations, factions, quests, or items — their own prep skills.
- Writing `vault/campaigns/shattered-sea/pcs/` directly —
  `transcript-ingest`'s move exclusively.
- Maintaining a persisted party-combat-intelligence file — dropped by
  design (see `combat-calibration.md`'s explanation); calibration is
  recomputed fresh each time from what's already on the wiki.
