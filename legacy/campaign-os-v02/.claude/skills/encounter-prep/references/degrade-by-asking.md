# Degrade by asking

The recurring gaps — unanswered interview questions, a missing PC
connection, an ambiguous stub-check hit, no party stats for a
combat-capable entity — bind via `vault/refs/vault/_common/degrade.md`.
This skill's own cases, on top of those:

- Named antagonist, unclear if they'll recur → ask; the answer decides
  `.claude/skills/draft-content/references/npc.md` hand-off vs. inline stats, and guessing wrong means redoing
  the page in the wrong place.
- No `## Session Log` data for the party yet → say the calibration is
  `[theoretical]` and proceed from the standard CR baseline; don't invent
  false confidence.
