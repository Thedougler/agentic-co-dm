# Encounter Type Router

Classify before designing — the type shapes which output sections carry
the weight:

| Type | Primary sections | Notes |
|---|---|---|
| **Standard combat** | Challenge Calibration + Run Sheet + Raising/Lowering the Stakes | Default path |
| **Social** | Drama Suite is primary; Lowering the Stakes = social leverage the party can spend | Challenge Calibration optional |
| **Skill challenge** | Skill Track (3–5 skills, DC tiers, failure consequences) replaces Challenge Calibration | No initiative |
| **Ambush/chase** | Terrain Shift fires round 1; Lowering the Stakes = escape or reversal | Fast, asymmetric |
| **Hybrid** | Classify the primary mode, add secondary-mode elements | Most real encounters are hybrids |
