# Output structure — mapped onto the pc template

Template headings stay fixed, in order, nothing added or removed:
`## Overview · ## Backstory · ## Arc Notes (DM Only) · ## Session Log`.
The 20 answers route by content, not as a preserved Q&A transcript — no
"Interview Answers" section exists on the pc template, and a raw Q&A dump
duplicates what these sections already state in synthesized form.

**`## Overview`** — dossier-style bolded-label lines, third person, present
tense (the shape every existing `vault/campaigns/shattered-sea/pcs/*.md` page already uses — match it,
don't invent a new one):

+ **Class:**/**Background:**/**Player:** line.
+ A sensory first-impression line from Q2 ("walk through the door").
+ **Species:**/**Languages:** if the interview surfaced them.
+ **Mortis:** from Q4's *visible* half only — the Mark itself and its
  mechanical shape. Whether *they* know it's there is Arc Notes material
  if the player wants it hidden from the table, Overview if not (ask which,
  don't guess).
+ **Core drive:** from Q5/Q6.
+ **Beliefs and limits:** from Q8, Q9, Q17.
+ **Current pressure:** from Q7 plus whatever from Q10 is presently active,
  not just historical.
+ **What they carry:** from Q12 (the item with a story) — wikilink it if
  it's an existing `vault/campaigns/shattered-sea/items/` page, plain prose if not yet one.

**`## Backstory`** — 3-6 paragraphs of prose, third person, DM's-notes
style (point-first, concrete) — not a character sheet, no bullet points.
Draws from Q10
(life before), Q11 (hardest survival), Q16 (the trusted person), and Q13/
Q17 if the player wants them table-visible.

**`## Arc Notes (DM Only)`** — the hidden half of anything the player
marked as a secret from the table, not from the DM: Q4's "do they know"
half if hidden, Q13 if the player wants it kept from other players, Q15
(enemies), Q18 (the compromise), Q19 (what would change things if
revealed). State each as an unresolved thread the DM can use, same shape
as an existing PC's Arc Notes section (see any `vault/campaigns/shattered-sea/pcs/*.md` page for the
pattern) — never invent a resolution, these are open threads.

**`## Session Log`** — starts empty. This section fills after the
character has actually played, not from the interview.
