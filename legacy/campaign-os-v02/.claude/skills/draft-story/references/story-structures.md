# Story structures — shapes a beat journey can take

The repo's single index of story-structure frameworks, at campaign scale: a
"story" here is a quest line, a session, a season, or an NPC/faction arc —
not a novel. Pick a shape before offering beats; the shape constrains which
candidate beats make sense next. Full detail for each shape lives in one of
three files, split by which cluster a drafting run actually reaches:

- `.claude/skills/draft-story/references/story-structures-classic.md` — the prose-fiction
  cluster (Three-act, Fichtean curve, In medias res, Seven-point,
  Kishōtenketsu, Hero's Journey, Frame narrative, Circular/bookend,
  Non-linear shapes).
- `.claude/skills/draft-story/references/story-structures-campaign.md` — the campaign/sandbox
  cluster (Episodic structure, Convergence Arc, The Slow Burn, The
  Escalation Ladder, The Reversal Arc, The Pyrrhic Arc, Parallel Threads,
  The Mystery Box, The Cliffhanger).
- `.claude/skills/composing-beats/references/audits.md` — diagnosing a
  stalled or flat journey, consulted only once a pattern has already
  stalled.

`.claude/skills/composing-beats/references/composition.md` § Sandbox
narrative devices and the quest guide's
`vault/refs/vault/quest/references/structure.md` both cite this catalog
rather than restate it — edit patterns in the file that holds them, not

## Classic (prose-fiction) shapes

Full detail: `.claude/skills/draft-story/references/story-structures-classic.md`.

- **Three-act structure** — the plain default: setup → confrontation →
  aftermath, applied at session/arc/campaign scale simultaneously.
- **Fichtean curve** — rising action immediately, a chain of crises, then
  aftermath; no flat exposition.
- **In medias res (with flashback)** — start in the middle, fill in how
  they got here; default opening mode for sessions and scenes.
- **Seven-point structure** — Dan Wells' plot architecture: plan the
  ending first, then start the party in the opposite state.
- **Kishōtenketsu (four-act, no central conflict)** — turns on
  recontextualization, not opposition; fits downtime and lore reveals.
- **The Hero's Journey (monomyth)** — Campbell's 12-stage mythic
  structure, for a whole campaign or a season-length PC transformation.
- **Frame narrative** — a story within a story; NPC testimony, visions,
  a bard's tale the party later walks into.
- **Circular / bookend structure** — end where you began, transformed.
- **Non-linear shapes** — reverse chronology, parallel timelines,
  mosaic/fragmented.

## Campaign / sandbox shapes

Full detail: `.claude/skills/draft-story/references/story-structures-campaign.md`.

- **Episodic structure (session-to-season shape)** — loosely connected
  episodes, same characters; the natural shape of a campaign season.
- **Convergence Arc** — 3–5 independent threads collide at a single
  high-stakes point; plan the threads, not the collision.
- **The Slow Burn** — seed → repetition → revelation → payoff, spread
  across many sessions; design for discoverability, not a scheduled reveal.
- **The Escalation Ladder** — stakes climb rung by rung: personal →
  communal → regional → existential.
- **The Reversal Arc** — a fortune or perception inversion built as a
  structural condition on a major NPC or faction.
- **The Pyrrhic Arc** — the party achieves the objective, but winning
  reveals or causes a real cost.
- **Parallel Threads** — several storylines advance between sessions
  whether or not players observe them.
- **The Mystery Box** — a compelling unknown players pursue because it's
  self-motivating, solvable or atmospheric.
- **The Cliffhanger** — beats-level device; `writing-cliffhanger-beats`
  skill owns construction and quality gate.

## Choosing a structure

| Journey type | Best shapes |
|---|---|
| Standard quest line | Three-act, Seven-point, Escalation Ladder |
| Heist / chase / one-shot | Fichtean, In medias res |
| Mystery / investigation | In medias res, Reverse chronology, Mosaic, Mystery Box |
| Season / campaign arc | Episodic, Hero's Journey, Three-act, Convergence Arc |
| Downtime / character session | Kishōtenketsu, Circular |
| Lore reveal / NPC testimony | Frame narrative, Parallel timelines |
| PC transformation arc | Hero's Journey, Circular, Reversal Arc |
| Faction/world threads running between sessions | Parallel Threads, Convergence Arc |
| Slow-build campaign mystery | The Slow Burn, The Mystery Box |
| Post-victory complication | The Pyrrhic Arc |
