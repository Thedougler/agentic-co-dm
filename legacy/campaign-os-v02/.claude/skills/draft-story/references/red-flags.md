# Red flags — you are rationalizing past the gate

Reached from [SKILL.md](../SKILL.md)'s gate and rails, the moment you catch
yourself arguing an item of `DS1`–`DS9` away.

Violating the letter of these rules is violating their spirit. There is no
scope small enough, no session close enough, and no GM hurried enough to
exempt one — a quest story runs the same nine items, just shorter.

## The excuses, and what is actually true

Every row was typed by a real agent handed a real deadline. They are not
hypothetical.

| The thought | Reality |
|---|---|
| "SKIP (time pressure): deep craft work, revision passes, skill invocations" | The gate is what deadline pressure exists to defeat. A skipped `DS5` does not save Thursday — it ships the summary the GM would have written themselves. |
| "FILL GAPS (minimal, no skills)" | "Minimal, no skills" is the failure with its own label on it. The steps scale down; they do not turn off. |
| "Find the Session 12 run guide, read what's already sketched" | Opening the run guide first inverts the pipeline. The story is `DS1`'s target; the guide is derived from it at `DS9`, never the reverse. |
| "The DM already sketched it, so most of the thinking is done" | A sketch is `DS1`'s scope input, not a substitute for the chapter. Notes that were never written as prose have not been tested as prose. |
| "One-pass clarity check for gaps, no rewrites or polish" | `DS6` and `DS7` are not polish-for-its-own-sake — `DS7`'s lint findings force the rewrites `DS8` would otherwise score against dead sentences. |
| "no draft-story skill needed — time pressure + thinking already done" | Naming the skill and skipping it is the failure this file exists for. `DS1`–`DS9` are cited by tag with evidence, or they did not run — and `npm run lint` returns W47 on a run guide with no story on the shelf, so the skip does not even survive the `npm run lint -- <path>` you already planned. |
| "Skip (not needed for Thursday): Draft-story (DM has the thinking)" | The DM having the thinking is `DS1`'s input, not `DS5`'s output. A guide derived from a sketch ships the sketch. |
| "The scope is one quest, too small for nine steps" | For a small scope the chapter is three paragraphs and `DS4` is `N/A`. That is the workflow running, not the workflow skipped. |
| "I'll write the pages and back-fill the story after" | Nothing back-fills. A page derived from notes locks the shape the story was supposed to find. |
| "I already know this NPC" | You know a page you have not read this session. `DS2` pastes the hit or it did not happen. |
| "The register is obvious from the material" | Then it costs one line to write. `DS3` unwritten is `DS3` unheld — a death drafted without it arrives in the register of the sentence before it. |
| "QC first, then lint — saves a round" | It spends one. The checker's own lint gate returns `LINT-DIRTY:` and judges nothing. |
| "The draft reads finished to me" | You hold the context the draft exists to supply, so you cannot read it cold. That is `DS8`'s whole job. |
| "I'll pick the strongest beat and write it" | It spends the GM's authorship to save your tokens. `DS4` offers 2-3 and the GM picks. |

## Stop the moment you are typing one of these

- "SKIP (time pressure)" / "no skills" / "minimal, no skills"
- "no draft-story skill needed" / "Skip: Draft-story" — naming the skill in a skip list is not routing past it
- "quickly" / "don't over-process" as a reason to drop a tag rather than shorten it
- "most of the thinking is done"
- "Find the run guide" / "Read `vault/_templates/`" before `DS9`
- "back-fill the story after"
- "I'll polish it later" in place of `DS6`
- Any `<type>-prep` skill or template instantiation before `DS9` is signed off

Each one means: stop, return to the tag you skipped, and run it.
