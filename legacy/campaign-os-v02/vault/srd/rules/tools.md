# Tools (5e SRD)

A tool helps a character make specialized ability checks, craft items, or both. A tool's description includes the tool's cost and weight, plus the following entries.

- **Ability.** The ability to use when making an ability check with the tool.
- **Use.** Possible actions with this tool in a single use, with DCs for each.
- **Craft.** What you can craft with the tool, if anything. For crafting rules, see "Crafting Nonmagical Items," "Brewing Potions of Healing," and "Scribing Spell Scrolls" (in the main Equipment page).
- **Variants.** Shows any tool variants. Each requires separate training.

## Tool Training

Training with a tool adds the Training Bonus to any ability check made that uses the tool. Training in a skill that's used with that check grants Advantage on the check too.

Character features might grant training with a tool. A monster has training with any tool in its stat block.
