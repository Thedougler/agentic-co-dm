# Ability Score and Modifier

A creature has six ability scores: [[strength|Strength]], [[dexterity|Dexterity]], [[constitution|Constitution]], [[intelligence|Intelligence]], [[wisdom|Wisdom]], and [[charisma|Charisma]]. Each score has a matching modifier. Add that modifier to any D20 Test you make with the ability. Add it too when a rule says to.
