# Breaking Objects

Attacks and spells can harm objects as described below. If an object is fragile, a skilled GM might allow a creature to break it automatically with an Attack or using an action.

**Armor Class.** The Object Armor Class table lists AC values for different substances.

table: object armor class

| AC | Substance           |
|----|---------------------|
| 11 | Cloth, paper, rope  |
| 13 | Crystal, glass, ice |
| 15 | Wood                |
| 17 | Stone               |
| 19 | Iron, steel         |
| 21 | Mithral             |
| 23 | Adamantine          |

**Hit Points.** An object breaks at 0 Hit Points. The table below shows Hit Points for fragile and resilient objects (Large or smaller). For larger objects, split them into Large sections and track each separately. Destroying part of an object may cause collapse.

table: object hit points

| Size                        | Fragile  | Resilient |
|-----------------------------|----------|-----------|
| Tiny (bottle, lock)         | 2 (1d4)  | 5 (2d4)   |
| Small (chest, lute)         | 3 (1d6)  | 10 (3d6)  |
| Medium (barrel, chandelier) | 4 (1d8)  | 18 (4d8)  |
| Large (cart, dining table)  | 5 (1d10) | 27 (5d10) |

**Damage Types and Objects.** Objects resist Poison and Psychic [[damage-types|damage types]], though Bludgeoning smashes well and Fire harms [[paper|Paper]]. You decide which other types work best, and some materials gain Vulnerability or Resistance.

**Damage Threshold.** Big objects, such as castle walls, often have extra resilience represented by a damage threshold. *See also* "Damage Threshold."

**No Ability Scores.** Objects have no ability scores, so they can't attempt ability checks or saves unless a rule says otherwise.
