Shape reference only, never copy these placeholder lines into a real
script; `vault/campaigns/shattered-sea/pcs/va-scripts/perrin-black-jaw-voice-script.md`
is the worked exemplar. Opens with a real VO-industry slate convention
("Hi, this is [name] for [project]") adapted in-fiction — the rest of
the roast/two-phase-arc structure is this repo's own invention layered
on top of it.

(Try to stay as in character from now on, its okay if you lose character just stop, breathe, and continue. Capturing how you, and/or your character, naturally speak is the point.)

I am reading for <Character Name>

Sincere line introducing the character — name, role, one true flattering detail.

A second sincere line, one concrete detail (an object, a relationship, a habit).

An easy tongue-twister folded in as something the character would plausibly say — a roll-call, a tally, a habit (light alliteration, one repeated sound).

A third sincere line planting the compliment the ending will later invert.

(in character)

A harder tongue-twister, still something the character would plausibly say — more repeated consonants, still ordinary words.

*(like Kirk)*
A sincere line building toward the phase break.

*(quickly)*
The hardest tongue-twister in the script so far, still folded in naturally — dense consonant clusters, quick repetition, still real words, ending right at the midpoint.

(calmly)

A line that reads as sincere but is the first deniable crack in the self-roast.

(sarcastically)

A light, affectionate jab at one named party member — a running gag or callback, never aimed at the player.

(wry, like you already know better)

A line where the self-roast joke is now visible but still gentle.

(furiously)

A line that lands harder — one specific, traceable self-roast fact.

(whispered)

A quiet beat — dynamic extreme #1.

(shouted)

A loud beat — dynamic extreme #2.

(earnestly)

A longer passage where the character sincerely defends the exact thing being roasted, oblivious to how it sounds.

(delighted)

A second light, affectionate jab at a different named party member.

(sarcastically)

An overt self-roast line — no deniability left.

(grinning)

The closing line — calls back to the opening, now openly rating the character.
