## The Language

State plainly what this language is and who speaks it: which peoples or
communities hold it, whether it is a mother tongue or a trade/second
language, and how widely it carries (a village dialect vs. a
continent-spanning lingua franca). Name what's currently active about it,
a dialect drifting apart, a trade tongue displacing a native one, a
language dying out, or say explicitly that it's atmospheric texture with
no hook. Never leave it ambiguous. State which PC's thread this pulls on,
or the DM's explicit call that it's core world-texture with none. Never
default to silence on this point.

## Script & Speech

Whether this language is spoken only, written only, or both, stated
plainly — never assume a spoken language has a script or that a written
form shares its shape with the spoken one. If it has a script, name it
and describe its form (letters, syllabary, glyphs, a non-visual medium
like knot-work or scent-marking) and who is actually literate in it. If
it borrows another culture's or language's script to render its own
sounds, say so. Delete this section outright if genuinely nothing beyond
"spoken, no script" is known yet — never fill with a placeholder.

section. OPTIONAL, this section only exists once dialectal spread or a
speaker boundary is understood — delete outright if none has real content
yet, never fill with a placeholder.
