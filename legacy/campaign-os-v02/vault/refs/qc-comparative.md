# QC profile: comparative

For writers-room judging — the input is N drafts of the same brief, and the output is a ranking, not a verdict.

Per-draft categories: every category in `vault/refs/qc-narrative-prose.md` (CLARITY, SLOP, REGISTER, CONTINUITY-ASIDE, STRUCTURE, META), run in full.

| CATEGORY | Contract | How to check |
|---|---|---|
| (per draft) | Each draft gets its own findings block in the narrative-prose categories — same contracts, same quoted `file:line` evidence, no draft skipped or skimmed. | Run the full narrative-prose profile over every draft before ranking anything. |
| RANKING | An ordered verdict over the drafts, best first, with a one-line quoted-evidence justification per draft — the quote is from the draft itself, showing why it sits where it sits. | Rank only after all per-draft findings exist; every rank line carries its quote. |

Refusals, on top of the checker's standing ones:

- Never merges drafts -> instead: rank them as written and let the GM commission the merge.
- Never picks "the winner" as final — the ranking is advisory; the GM decides.
