# Exemplar Quality Rubric — Markdown-native layout

Continued from [exemplar-quality-rubric.md](vault/refs/exemplar-quality-rubric.md).
Each item is the pass/fail check; the section structure that meets it is
specified by the page's own template under `vault/_templates/`.

## G. Markdown-native layout

- **R27 — Bold scan tokens at point of use.** Check: for any
  name/reward/DC a runner searches for mid-scene, its line carries the bold
  token, not just the unit's opening mention. *([Night Hunter](docs/exemplars/the-night-hunter.md)'s
  bolded **howl**/**footfalls**/**scream**; [Potent Brew](docs/exemplars/a-most-potent-brew.md)'s
  inline DC/reward citations.)*
- **R28 — Bold-keyword bullets are the default DM-facing prose unit.**
  Check: a DM-facing section reads mostly as bold-led bullets; any surviving
  paragraph is a handful of sentences, never a block the DM must mine for
  facts. *([Night Hunter](docs/exemplars/the-night-hunter.md): everything
  bulleted with a bold retrieval handle.)*
- **R29 — Conditional depth is typographic, not prose.** Check: every
  conditional in DM-facing prose is an indent, not a sentence clause.
  *([Night Hunter](docs/exemplars/the-night-hunter.md)'s indented
  conditional sub-bullets.)*
- **R30 — Unit openers name the required beats.** Check: reading
  only the opener line, a DM can state the unit's shape without reading on.
  *([Silverpine Watch](docs/exemplars/fall-of-silverpine-watch.md)'s
  encounter summaries.)*
- **R31 — Reference sits adjacent to the beat that needs it.** Distinct from
  R6's quarantine-and-link rule for stat blocks and lookup material: R31
  governs an artifact the DM's eyes need in the moment, which co-locates
  rather than merely links. Check: for any artifact a beat uses in the
  moment of running it, it sits in the same section or is transcluded
  there, not only reachable via a separate hop. *([Potent Brew](docs/exemplars/a-most-potent-brew.md)'s
  map-on-spread; [Night Hunter](docs/exemplars/the-night-hunter.md)'s
  rumor-table-beside-beat.)*
- **R32 — Visual hierarchy substitutes are named, not lost.** Check: for any
  visual-hierarchy device an exemplar analysis names as print-only, a
  markdown equivalent is named and pages actually use it.
  *([Silverpine Watch](docs/exemplars/fall-of-silverpine-watch.md)'s
  color-coded rules text → structural convention; [Serpent Kings](docs/exemplars/tomb-of-the-serpent-kings.md)'s
  art-as-tonal-signal → prose equivalent.)*
- **R33 — Table vs prose vs callout is a selection rule, not a habit.** Check: no page
  defaults to prose for a 3+-case parallel set, and no roll or contingency
  sits in bare prose where a callout exists for it.
  *([Silverpine Watch](docs/exemplars/fall-of-silverpine-watch.md)'s
  typed check format; [Serpent Kings](docs/exemplars/tomb-of-the-serpent-kings.md)'s
  per-room scan boxes.)*
