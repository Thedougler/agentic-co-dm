# Draft — Deity Checklist

Run `vault/refs/vault/_common/checklist.md` first; these are the
deity-only additions.

- [ ] `domains:` names at least one real domain in this setting's own
      vocabulary, never a borrowed D&D domain list and never left empty.
- [ ] `## Portfolio & Manifestation` commits to exactly one manifestation
      stance — never hedges across several.
- [ ] Any church, cult, or clergy with its own leadership or goals is a
      separate `type: faction` page, linked by `[[wikilink]]` from
      `## Worship` — not described as part of this page.
- [ ] `worship_status` reflects the deity's actual current worship state
      (active/dormant/forgotten/usurped), not left at the template default
      by accident.
- [ ] Any myth, prophecy, or origin story with no active-worship dimension
      lives on a `type: lore` page instead, linked here rather than
      retold.
- [ ] `within:` (if set) resolves to a real pantheon or divine-index page,
      quoted, full vault-relative path, no alias.
