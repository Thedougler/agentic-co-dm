# Monster Combinations for a Hard Challenge (5e Monster Builder)

When designing encounters, GMs often start with a concept for the number of foes the characters will face: a squad of four monsters going one-to-one, a larger force of six or eight swarming the heroes, a stronger boss/captain backed by a few subordinates, or a single dangerous foe.

This guide provides guidelines for combining creatures of different challenge ratings (CR) to build these encounter concepts. Pick a concept, consult the appropriate table for the number of characters in the game, look up the average character level, and read off the monster CRs needed to build the encounter.

## Hard Challenge Level Monster Combinations

The challenge ratings in the tables below are geared toward creating encounters that are a hard challenge. The encounter concepts reflect some of the most common combinations of foes.

### One Monster

The leftmost column notes the CR expected for a solo creature whose statistics and capabilities can build a hard challenge. Running an encounter for a single solo monster is always tricky, so make sure an intended solo creature is up to the challenge.

### Two, Four, Six, Eight, or Twelve Monsters

The other columns under "Monsters of the Same CR" allow challenging the characters with a number of creatures of the same CR, and usually the same type. For example, a hard challenge for four 4th-level characters could constitute six scouts (CR 1/2) or two ogres (CR 2).

Using creatures of the same type allows quickly and simply telling a story as the characters find themselves in an ogre market cavern, a caravan under attack, a room with mimics, and so forth. Using the same monsters also lets the GM focus on a single stat block for ease of play.

### One Boss + X Monsters

Encounter concepts often suggest a group of creatures led by a more formidable leader. Each of the "Boss Scenarios" columns pairs up one boss and a number of subordinates of lower CR. For example, a group of four 3rd-level characters could face one boss of CR 2 and two subordinates of CR 1/2 — perhaps an ogre explorer and the two rust monsters they've befriended.

The rightmost column under Boss Scenarios builds encounters with eight minions, two lieutenants of a higher CR, and one boss whose CR is higher again.

## Using the Tables

1. Select the appropriate table, based on the number of characters in the party — four, five, or six.
2. In the leftmost column of the selected table, find the row containing the average character level for all the characters. (To find the average, add up all the characters' levels, then divide by the number of characters and round down.)
3. Follow that row to the column containing the encounter concept to use. For example, to create an encounter with one boss and three lesser monsters, go to the "1 Boss + 3 Monsters" column.
4. The entry cross-referenced notes the CR(s) of the creature(s) in the encounter. If a multiplier is indicated, that's the number of monsters for the preceding CR. For example, challenging four 3rd-level characters with the encounter concept of one boss and three monsters yields an entry of "2 + 1/4 (×3)" — this means one CR 2 creature acting as the boss, and three CR 1/4 creatures acting as subordinates.
5. Choose the monsters. If building a quick encounter, the recommendations in "Monsters by Adventure Location" are a good starting point. (That section is not part of this source document.)

## Scaling Encounters

Each of the tables below is intended to build a hard encounter. Other challenge levels can be built by adding or subtracting a modifier to the party's average character level:

- For a deadly challenge: +1 or +2
- For a medium challenge: −2
- For an easy challenge: −4

For example, when building an encounter for four 10th-level characters, use the row for 8th-level characters to create a medium challenge.

In all cases, be cautious with scaling. Encounters of certain types and at certain levels will be harder or easier than the approximation would indicate. Always be prepared to adjust encounters on the fly.
