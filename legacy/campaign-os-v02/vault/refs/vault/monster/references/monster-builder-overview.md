# The Lazy GM's 5e Monster Builder Resource Document (Overview)

By Scott Fitzgerald Gray, Teos Abadía, and Michael E. Shea. Updated 18 January 2024.

This document includes tools and material for building, modifying, and running monsters for 5th edition fantasy roleplaying games.
