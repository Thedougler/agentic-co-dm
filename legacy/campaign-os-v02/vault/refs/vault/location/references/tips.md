# Location Tips

The source is a bare checklist with no elaboration on any item. The source URL (https://phd20.com/blog/how-to-build-fantastic-locations-dnd) points to a fuller blog post explaining each item, but that post's content was not captured in the source file and is not reproduced here.

## Checklist

- One defining trait
- Familiar
- Functional
- Fantastic
- Description
- Change
