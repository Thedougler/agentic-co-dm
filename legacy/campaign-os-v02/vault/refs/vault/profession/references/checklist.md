# Draft — Profession Checklist

Run `vault/refs/vault/_common/checklist.md` first; these are the
profession-only additions.

- [ ] The Job-Not-Package test was actually run — this page carries no
      character-creation mechanics (ability scores, a feat, starting
      equipment); those live on a matching `[[background]]` page instead,
      linked inline if one exists.
- [ ] The Setting-Wide test was actually run — no single faction's own
      membership already owns this rank; if it does, the rank stays on
      that faction's page and this page doesn't exist.
- [ ] `## Nature` states what the profession concretely is — the activity
      or the position's function and authority — not a generic "respected
      job" line.
- [ ] `## Entry & Advancement` names a real path in (apprenticeship,
      appointment, election, inheritance, purchase, examination), not
      "somehow."
- [ ] `## Standing`'s Typical earnings line uses this setting's own
      currency unit, and states "none" outright rather than leaving the
      line blank when the position isn't paid.
- [ ] `## Marks & Removal`, if present, names a real insignia/accoutrement
      or a real way to lose the position — deleted outright otherwise,
      never left as an empty or placeholder heading.
