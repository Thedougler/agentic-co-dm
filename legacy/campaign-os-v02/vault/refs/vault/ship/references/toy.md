# Ship Toy field rules (good/bad pairs)

Same discipline `.claude/skills/composing-beats/references/runtime-surface.md` §3 states generically, applied to each Ship Toy
field:

- `tier_justification` — ✓ "Tier 1 sloop — affordable at the party's current funds,
  enough cargo for the smuggling runs this arc needs." ✗ "Tier 1 because that's what
  they can afford" (states the constraint, not the fit).
- `pc_connection` — if you can't answer this in one sentence, the page isn't ready to
  generate (the PC-Connection Requirement).
- `acquisition_method` — ✓ "Prize — boarded during the harbor raid, then repaired at a
  friendly shipyard." ✗ "They got it somehow."
- `crew_composition` — ✓ "&lt;PC name&gt; as Captain, a hireling Bosun, Navigator role
  currently open." ✗ "Fully crewed."
- `current_status` — ✓ "Docked, party-controlled, Worn condition (post-raid
  patching)." ✗ "It's doing fine."
- `bastion_facilities` — ✓ "None — pure vehicle for now." ✗ "Not really set
  up as a bastion yet."
