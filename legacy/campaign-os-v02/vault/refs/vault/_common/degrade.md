# Draft — Degrade By Asking

A gap the interview did not answer is a question for the DM, never a blank
to fill with a plausible default. Degrading by asking means naming the
specific gap and stopping there. These are the cases that recur across
every type, each owned by the guide that names its own escalation; a
per-type guide adds its own on top.

- **Interview questions still unanswered** -> escalate per
  `vault/refs/vault/_common/interview.md`'s never-invent list.
- **Ambiguous stub-check hits** -> `vault/refs/vault/_common/queries.md`'s
  Reading the result: name the ambiguity, ask.
- **Missing PC connection, including when nothing genuinely connects** ->
  `vault/refs/vault/_common/hard-rules.md`'s PC-Connection Requirement; ask
  for the mechanism, not a placeholder like "ties into the group's arc".
- **No party stats for a combat-capable entity** ->
  `vault/refs/vault/_common/hard-rules.md`'s Calibrate Against The Real
  Party.
- **A review gate has not run** -> `vault/refs/vault/_common/lifecycle.md`'s
  DM Review Gate; leave `status: draft`.
- **Unclear which content type owns a page**, once both candidates'
  boundary sections in `vault/refs/vault/_common/handoffs.md` still don't
  resolve it -> ask, rather than forking a duplicate page in the nearest
  type; a fact wikilinked to its real page from here is the correct
  outcome.
- **An abstract answer where a concrete one is needed** — a theme given as
  "hope" or "danger" -> ask what it looks like rather than picking a visual
  for the DM.

## What does not need asking

A question whose answer any real culture, place, or person in this world
would obviously already have — a spear-and-poison culture also has bows, a
port has rope, a city has beggars — is a gap in the wiki, not a gap in the
world -> write the one-line addition and report that you did. Escalate only
what a player would notice or a plot would turn on.
