# Draft — Culture Checklist

Run `vault/refs/vault/_common/checklist.md` first, these are the
culture-only additions.

- [ ] No biology, trait, or mechanical-ancestry content on the page, that
      stays on the `species` page (Culture Absorbs, Species Does Not).
- [ ] Every festival or rite in `## Customs & Traditions` reads as a
      recurring institution, not a single dated incident, a one-off
      happening is an `event` page linked from here instead (Institution,
      Not Incident).
- [ ] `peoples` lists every species or community that actually holds this
      culture, or is deleted outright when membership has no fixed set.
- [ ] `within` names one real region or settlement, or is deleted outright
      when this culture is not rooted in a single place.
- [ ] `## Customs & Traditions` and `## Naming` are each present only when
      real content fills them, deleted outright otherwise, never left
      empty or filled with a placeholder line.
