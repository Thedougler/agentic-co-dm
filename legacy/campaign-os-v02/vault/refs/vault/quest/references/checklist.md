# Quest Checklist Reference

Quest-only additions to `vault/refs/vault/_common/checklist.md`. Run
both before calling a quest page done.

- [ ] A structural pattern is named in `## Secrets & Clues` and actually
      matches the quest's real content (The Structural Pattern Choice,
      `.claude/skills/draft-content/references/quest.md`).
- [ ] `## Beats` holds only the seed (The Beats Handoff,
      `.claude/skills/draft-content/references/quest.md`).
- [ ] `## Outcome` left empty (no pre-filled entries).
- [ ] `quest_status` set to `rumored`, its starting value — never advanced
      by this guide (The Quest Status Ladder,
      `.claude/skills/draft-content/references/quest.md`).
- [ ] Every DM-only synthesized conclusion in `## Secrets & Clues` (true
      stakes/opposition, prepped reveals) names its Strongest Objection and
      a testable search query
      (`vault/refs/vault/quest/references/output.md` § Strongest
      Objection).
