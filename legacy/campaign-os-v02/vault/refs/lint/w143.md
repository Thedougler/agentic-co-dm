# W143 — retired session-unit page types

`W143` fires on a `vault/episodes/` page whose type was retired when beats
absorbed the narrative units
(`docs/adr/0061-beats-absorb-moments-forks-and-sequences.md`).
The retired types: `passage`, `moment`, `fork`, `sequence`, `dm-screen`.

## Fix

- A playable dramatic unit is a `type: beat` page, instantiated from
  `vault/_templates/_episodes/_beat_*.md`.
- A crossing between places belongs on a `type: route` page.

A frozen episode directory (one already through the publish gate) is exempt —
the rule skips it, and corrections there go through `canon-review` instead.
