# W85 — a markdown link with a dead target

`W85` fires on a `](target)` markdown link whose relative path resolves to no
file in the repo.

## Fix

Find the target's real path with `git ls-files | grep <basename>` and repoint
the link. When the target is genuinely gone, delete the link.

A page inside `vault/` is linked as a `[[wikilink]]`, never as a relative
markdown path — a wikilink survives the page moving. Renaming the link text
while leaving the dead target still leaves the reader with nowhere to go.
