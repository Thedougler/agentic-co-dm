# W87 — markdown defects (pymarkdown)

`W87` carries one pymarkdown finding. The `MD###` code at the head of the
message names the defect — `MD009` trailing spaces, `MD022` blank lines around
a heading, and so on. Each code is documented at
<https://pymarkdown.readthedocs.io/en/latest/plugins/>.

## Fix

Fix the defect at the reported line.

Adding a `disable_rule_by_identifier` call in `_build_api()`
(`utils/wiki-cli/src/wiki_cli/producers/markdownlint.py`) is a configuration
decision that needs its own written reason. It is never the way to clear a
finding in front of you.
