# W82 — oxlint findings on JS and mjs

`W82` carries one oxlint finding. The slug at the head of the message is the
oxlint rule that fired — `no-unused-vars`, `no-explicit-any`, and so on.

## Fix

Run `node_modules/.bin/oxlint <path> --fix` for the mechanical ones, then
hand-fix what remains, the same turn.

None of these settle the finding: an `oxlint-disable` comment, a widened
`catch`, or a new entry in `.oxlintrc.json`'s off list. Each one silences the
report and leaves the defect in the file.
