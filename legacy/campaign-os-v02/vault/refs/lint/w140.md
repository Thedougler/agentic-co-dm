# W140 — episode file naming and session shape

`W140` checks the filenames inside an episode directory and the frontmatter
the overview carries.

## Fix

- Name the overview `eNN-overview.md` and set `session_shape:` to one of the
  nine session shapes (`vault/_templates/_episodes/_session_overview.md`).
- Name each episode run-guide `eNN-run-guide-<slug>.md`, with a slug unique
  inside that episode (`vault/_templates/_episodes/_session_run_guide.md`).

`NN` is the session number the directory holds, zero-padded to two digits.
