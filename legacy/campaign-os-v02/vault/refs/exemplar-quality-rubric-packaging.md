# Exemplar Quality Rubric — Adoption and packaging

Continued from [exemplar-quality-rubric.md](vault/refs/exemplar-quality-rubric.md).

## F. Adoption and packaging

- **R25 — Optional content is opt-in by design.** Optional systems are
  classified by impact, separable without breakage (and say so), end in named
  independent toggles, and heavy ones name a minimal starting subset. Check:
  any optional piece can be adopted alone; the document says what happens if
  you don't. *(Darker Dungeons' tiers, Variant Dials, Getting Started boxes;
  the Jinx's compromise variant.)*
- **R26 — Package by who holds it at the table.** Artifacts split by table
  function — player handout, runner text, map/visual, tracker, quick reference
  — not by authorship convenience; recurring state gets a tracker artifact.
  Check: for each thing a table needs to hold or mark, a dedicated artifact
  exists. *(Potent Brew's four files; Night Hunter's cards and maps; Darker
  Dungeons' sheets; Silverpine's prop handouts.)*
