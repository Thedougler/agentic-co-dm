# Stories Playbook: The prose-aesthetic profile (author aesthetic profile)

`vault/refs/stories/prose-aesthetic.md` is this repo's own instance of the
source playbook's author-aesthetic-profile methodology — read that file for
the GM's actual voice, and its own "Keeping this file live" section for how
it is built and updated; this page adds nothing to that procedure.

What this file still owns: the **section skeleton** below, a completeness
check for reviewing `prose-aesthetic.md` — which of these eight sections it
covers, and which it has deliberately left out.

Section skeleton (each populated from the author's own finished writing,
never from agent-drafted prose. Vague preferences like "I like short
sentences" produce vague feedback. Specific patterns like "I use
single-sentence paragraphs as ironic payoffs, not emphasis. Never suggest
expanding them" produce precise, calibrated feedback):

- **Core Aesthetic**: the unifying aesthetic across all written work. Genre, register, the kind of strangeness or truth pursued.
- **Prose Style**: how sentences actually work. Rhythm, length variation, fragments, narration versus interiority balance.
- **Narrator and Voice**: reliability, distance, whether perspective shifts are a device or an error in this author's work, use of free indirect discourse.
- **Structure**: how this author handles narrative architecture. Captured in documented preferences about timeline treatment and chapter design.
- **What You Do Not Do**: patterns to never suggest. Moves that would break the voice. Endings never to write.
- **Influences and What They Mean in Practice**: not a reading list. Specific techniques absorbed from admired writers and how they appear in this author's own work.
- **Developmental Feedback Calibration**: how Claude should interpret this author's choices during an editing pass. What looks like an error but is intentional. Which interpretations Claude should always challenge.
- **Source Note**: how the profile was built (from which works, when last updated). Update it when new material arrives.
