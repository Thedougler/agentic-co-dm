# Canon changes are proposals

**Status:** Superseded by constitution v7.0.0 principle X. The canon rule now lives in [`llm-wiki`](../../.agents/skills/llm-wiki/SKILL.md#canon).

Fun is the craft bar for how Work is written (pacing, TotM, encounter shape, DCs as play). Wiki facts (who lives, what is true, unrevealed secrets, RAW/homebrew the DM already set) do not change unless the DM accepts a canon proposal.

This rejects both silent invention and “nothing is sacred including continuity.” Play still wins at wrapup: the transcript updates the wiki after the session.
