# Agents do not run during sessions

The Co-DM authors prep before play and ingests the transcript after. During a session only the human DM is present. Live table proposals are out of scope until that decision is revisited.

This is the opposite of a live co-GM, which the name otherwise suggests. Prep must be complete enough to run without an agent. Foundry staging and theatre-of-the-mind copy happen in prep, not at the table.
