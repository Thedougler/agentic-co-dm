# Aruhe — Easy travel rewrite (canon update)

## Current state
Picking living fruit on Aruhe is **safe**. Predators no longer respond to taking. Matteo was wrong about the death-rule; Session 11 readings were panic, not law. Travel inland is now ordinary foraging country.

## Taking rule (retired)
The old living-claim hostility is removed from the page so parties can harvest freely. Western Landing no longer teaches the fallen-vs-living distinction.

## Hazards
Primary pressure deleted for ease of play. Memorial Grove / Hinewai noted only as scenery.
