# Ruin after enemies leave — labeled fixture

## Enemies-vanished test
Even with all hostiles gone/defeated, the place stays engaging via:

### Non-combat verbs / affordances
- **Study** mosaic cycles to learn which cistern feeds which garden.
- **Reroute** irrigation to flood or drain a wing.
- **Bargain** with remnant refugee camp outside (not combatants) for keys.
- **Harvest** luminous lichen for sale or light.
- **Consecrate / desecrate** the cracked altar to change faction posture on return.

### Payoff tied to promise (discovery / transformation)
Repairing the cistern network restores the hanging gardens — visible transformation and a trade good route. Mis-routing floods the archive (consequence).

### Guardrail
Nodes are worth visiting for routes, clues, resources, and changes — not because an encounter quota says so.
