# Design fixture: Ember-Latch (labeled invention — not vault canon)

## Five-sentence kernel
1. **Function:** Cliff-port where tide-locks hold cargo mid-air overnight.
2. **Fantastic:** Ember-moths nest in the latch chains and ignite if jostled wrong.
3. **Present conflict:** Stevedore guild vs moth-cult who feed the chains.
4. **Player promise:** Exploitation + Intrigue — use moths, bargains, or lock timing to move goods or people.
5. **Trajectory:** If nobody intervenes, next spring tide burns a third of the hanging cargo.

## 3Fs / contradiction / signatures
- **Fantastic:** Chains that hold cargo in empty air.
- **Familiar:** Busy dock politics and tide clocks.
- **Functional:** Merchants time loads to moth quiet hours.
- **Contradiction:** Safety requires feeding the same moths that can burn the town.
- **Signatures:** (1) ash-scored latch rings players can rotate, (2) moth-feed bowls on every pier, (3) burned cargo nets as climbable routes.

## Promise
**Exploitation + Intrigue** — choose guild bargain, cult offering, or sabotage the latch timing.

## Topology / life / clues / pressure / return
- Nodes: Tide Clock → Latch Yard → Cult Alcove → Guild Loft (loop via cargo nets; bypass via cliff goat-path; retreat to lower skiffs).
- Inhabitants: Guild wants quiet moths; cult wants fed chains; both move between visits.
- Clues: ash rings (physical), stevedore rumor (witness), tide ledger (document).
- Pressure: clock advances toward spring-tide burn if party rests without acting.
- Return: burned berth stays burned; moth population tracks prior feed/starve choices — no reset.
