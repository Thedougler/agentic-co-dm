# Recap checklist

- [ ] Source is a finished `session-wrapup` log or a bounded `session-transcript-ingest` packet.
- [ ] Recap contains only play-supported, table-visible events.
- [ ] Frontmatter uses `type: session`, `campaign`, `session`, `status`, `date`, `visibility: table`, and `tags: [session, recap]`.
- [ ] Named entities are wikilinked on first mention.
- [ ] Secrets, DCs, unearned names, and unused prep are excluded.
- [ ] Recap ends with an available player-facing hook, not a planned path.
- [ ] No hot/front/entity/AGENTS cascade was performed.
