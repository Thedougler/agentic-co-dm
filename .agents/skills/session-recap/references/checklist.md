# Recap checklist

- [ ] Source is play notes, a bounded `session-transcript-ingest` packet, and/or reconcile packet — not unused prep.
- [ ] Recap contains only play-supported, table-visible events.
- [ ] Path is `wiki/journal/sessions/<campaign-slug>/<NN>/Session-<NN>-Recap.md` (kebab; no spaces).
- [ ] Frontmatter uses `type: recap` (not `session`), campaign fields, and player-safe visibility after accept.
- [ ] Body uses `[!narration] Recap` (+ optional cold open + `## Wiki facts` pointers).
- [ ] Named entities are wikilinked on first mention.
- [ ] Secrets, DCs, unearned names, and unused prep are excluded.
- [ ] No durable `type: session` log, owner-page surgery, clocks, entity filing, or world-tick cascade.
