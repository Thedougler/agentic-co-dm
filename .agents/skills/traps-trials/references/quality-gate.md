# Quality gate

Verify every item before finishing:

* The challenge is a situation rather than a predetermined scene outcome.
* Its fictional purpose and mechanism agree.
* Meaningful danger is telegraphed before it lands.
* Essential progress does not depend on one successful roll.
* Investigation produces actionable information.
* At least two distinct solution vectors exist.
* Creative bypasses can be adjudicated from the mechanism.
* Failure creates a playable next state.
* Repeated interaction changes the state instead of repeating the same roll.
* Character abilities are allowed to matter.
* Multiple PCs can contribute.
* Consequences fit the fiction and severity of warning.
* The page makes no assumption about session order or required route.
* Persistent aftermath is stated.
* Existing canon is linked rather than duplicated.
* The human DM can run the content from the finished page alone.

Revise until every applicable item passes.
