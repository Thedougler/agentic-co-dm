# Reference gate

Browse only enough to calibrate. Summarize patterns in the dossier. Extract patterns, not protected expression — no distinctive names, lore, descriptive prose, or substantial ability text from copyrighted products.

## Procedure
1. Parse the brief into tier, intended rank/CR, role, environment, signature, damage/control expectation, party size, and 2024/2014 compatibility.
2. Find one official/public rules anchor for the mechanic or notation. Use the current SRD/public rules page when available.
3. Find peers covering: official numerical peer (same CR/rank/style when possible), role peer, mechanic peer. One creature may cover multiple categories; use at least two independent designs. Prefer at least one official specimen when one exists.
4. Record only actionable observations: chassis range, action cost, frequency, target count, tell, counterplay, and failure consequence.
5. Reject a reference if it is a forum assertion without a specimen, an unattributed repost of protected text, an obsolete rules assumption, or a design that cannot be compared by role and rank.
6. Produce the dossier. Stop research when the path is clear; do not browse for decorative inspiration.

## Quality gate
A usable reference is public or user-provided, relevant to 2024/2025 play or explicitly marked 2014, comparable by role/rank, and specific enough to expose a mechanic or number. Require: official numerical peer when possible, role peer, mechanic peer (≥2 independent designs), one counterplay observation, one uncertainty note. If a reference is inaccessible, substitute another specimen and mark “unverified.”

## Dossier
| Field | Record |
|---|---|
| Anchor | rule/notation and URL; what is certain |
| Peer A / role | rank, job, signature, action cost, defense |
| Peer B / mechanic | rank, target count, frequency, tell, answer |
| Shared pattern | what repeats across useful specimens |
| Deliberate deviation | why this monster differs |
| Counterplay | player answers and failure cost |
| Math note | expected attack/DC, HP/AC, three-round damage/control |
| 2014/2024 note | what was recalibrated or left compatible |
| Uncertainty | missing data, assumption, or test needed |

## 2014 recalibration
When a 2014 peer is useful, retain its fiction and decision loop but recalculate attack/DC, damage, HP, AC, save pressure, recharge, and action economy against current peers. Mark the conversion. Do not infer 2024 balance from a copied 2014 CR label. If no current peer exists, lower confidence and require a three-round playtest.

## Pattern extraction
Extract relationships—“one setup action unlocks a telegraphed payoff,” “high mobility trades away durability,” “a solo gets off-turn choices”—rather than sentences, named signature mechanics, or protected expression. Paraphrase all rules text and write original names and examples.
