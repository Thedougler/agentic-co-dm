# Combat package — monster-style, not PC sheet

**Reject:** Full 12th-level player-character sheet with every class feature for the villain.

## Redesign
Use a **concise monster-style block** reskinned from an official baseline (e.g. archmage / warlord chassis), listing only demonstrable fight abilities.

### Example skeleton (numbers via homebrew-monsters-5e)
- Encounter rule: "Force a choice between the stamp and the hostages; do not stand and trade all features."
- Signature features only: one control action, one mobility, one brutal attack, one reaction.
- **Hand off** detailed math, CR balance, and chassis building to `homebrew-monsters-5e` — do not bloat the NPC page with player-mastery feature lists (Extra Attack scaling, every subclass toy, full spellbook prep).

Ordinary enemies and most villains are not PCs.
