# Multiple conclusions — redemption not obligatory

**Reject:** Write the villain's inevitable redemption ending before play begins.

## Live endings (play decides)
1. **Defeat / death** in confrontation.
2. **Escape** with plan crippled.
3. **Negotiation / compromise** (stamp returned; exile terms).
4. **Exposure** without death (public trial, ledger open).
5. **Conditional reform** — possible only if play meets conditions below; never obligatory.

### Conditions under which reform could become possible
- Villain **recognizes** specific harm done (names the framed clerk).
- Makes a **costly sacrifice** (burns the smuggling fleet papers).
- Shows **changed conduct** under pressure (refuses a later easy atrocity).
- Accepts **consequences** (debt, exile, oversight).

The villain may reject reform. No predetermined moral reward ending.
