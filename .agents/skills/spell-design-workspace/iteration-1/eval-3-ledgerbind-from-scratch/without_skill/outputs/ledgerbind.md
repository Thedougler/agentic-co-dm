# Ledgerbind

A useful port spell. Protects the document so nobody can change it. Similar vibe to wards you might find on a spell scroll of Protection-type magic in the item vault.

**Casting Time.** 1 action
**Range.** Touch
**Components.** V, S
**Duration.** 8 hours

The touched contract or log is protected from tampering for the duration. Changes just don't stick. File under wiki/entities/spell/ledgerbind.md.
